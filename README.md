# 待機ループ (html_video)

1枚絵から生成する待機モーションビューア。素材は `assets/character.png` のみ。

- 足は全ての動きを合成した後に元座標へ強制固定（軸ズレなし）
- 演出 5 種（穏やか呼吸 / 疾風 / 臨戦 / 夢見 / 集中）＋ 使う/使わない切替
- エフェクト 8 種（桜吹雪 / キラキラ / 光の筋 / 霧 / 雨 / 刀の閃光 / オーラ / ビネット）個別 ON/OFF・強度
- 背景: プリセット / 単色 / 画像読込 / 透過
- 全体ループ 14.4 秒（継ぎ目なし）

操作: `Space` 再生/停止、`H` パネル表示切替。パネルの「足軸チェック」で固定領域と検証を確認できます。

公開: https://ryoheimongami8.github.io/html_video/

## 攻撃
- `A` キー / 「攻撃」ボタン / ステージのクリックで発動。終わると待機へ戻ります。「自動で繰り返す」で一定間隔ごとに発動。
- 素材は 60 フレームの居合 GIF を連番 WebP 化したもの（`assets/attack/`）。再生成: `python tools/extract_attack.py <gif>`（pillow / numpy / scipy）。
- 元 GIF は体が全体にドリフトして足が滑るため、全フレームで「後ろ足」を待機姿勢の接地点にピンするオフセットを自動算出（`meta.json`）。
- パネル「攻撃フレーム補正（足位置）」で 1 枚ずつ X/Y を微調整可能（ブラウザに保存）。赤線=後ろ足の接地基準、青線=前足の接地基準、丸=検出した足位置。

### 待機への戻りと残像
- 攻撃の最後に、最終フレーム→待機姿勢をオプティカルフローで補間した12枚（`r00〜r11`）を挟み、姿勢が飛ばないようにしています。再生成: `python tools/make_return_frames.py [枚数]`（`extract_attack.py` の後に実行。opencv-python-headless が必要）。f59 の手動補正を変えた場合は再生成してください。
- 攻撃の直前に待機の揺れを0へ収め、攻撃後に0から戻すので、前後の継ぎ目で絵が跳ねません。
- 残像: 攻撃中に過去フレームを色付きシルエットで尾のように重ねます。色モード（2色グラデ / 単色 / 虹 / 元の色）、色2つ、本数、間隔、濃さ、発光（加算）を変更できます。
