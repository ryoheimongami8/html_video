# 待機ループ (html_video)

1枚絵から生成する待機モーションビューア。素材は `assets/character.png` のみ。

- 足は全ての動きを合成した後に元座標へ強制固定（軸ズレなし）
- 演出 5 種（穏やか呼吸 / 疾風 / 臨戦 / 夢見 / 集中）＋ 使う/使わない切替
- エフェクト 8 種（桜吹雪 / キラキラ / 光の筋 / 霧 / 雨 / 刀の閃光 / オーラ / ビネット）個別 ON/OFF・強度
- 背景: プリセット / 単色 / 画像読込 / 透過
- 全体ループ 14.4 秒（継ぎ目なし）

操作: `Space` 再生/停止、`H` パネル表示切替。パネルの「足軸チェック」で固定領域と検証を確認できます。

公開: https://ryoheimongami8.github.io/html_video/
